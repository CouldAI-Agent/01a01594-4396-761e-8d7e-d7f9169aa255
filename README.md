# TikTok Video Downloader aur Chat App

Yeh ek Flutter application hai jo bilkul TikTok ki tarah kaam karti hai. Isme aap videos ko scroll kar sakte hain, unhe download kar sakte hain, aur apne doston ke saath chat bhi kar sakte hain. Yeh app har phone (Android, iOS) aur web par chalegi.

## Khasiyatein (Features)
- **Vertical Video Feed**: TikTok jaisa smooth scrolling experience.
- **Video Download**: Kisi bhi video ko download karne ka button.
- **Inbox/Chat**: Real-time chat aur messages check karne ke liye inbox screen.
- **Cross-Platform**: Yeh app mobile, tablet, aur desktop screens par chalne ke liye design ki gayi hai.

## Tech Stack
- **Flutter**: UI aur cross-platform support ke liye.
- **Video Player**: Videos play karne ke liye `video_player` package.

## Kaise Chalayein (How to Run)
1. Project ko clone karein ya download karein.
2. Terminal mein `flutter pub get` run karein taake packages install ho jayein.
3. App ko apne phone ya emulator par chalane ke liye `flutter run` command use karein.
